Để vận hành toàn bộ hệ thống từ đầu đến cuối, trước tiên cần khởi động hạ tầng Docker gồm MLflow, Prometheus và Grafana bằng lệnh `bash scripts/start_stack.sh`, sau đó chạy lệnh `uv run python pipeline.py` để huấn luyện mô hình v1 trên tập dữ liệu chuẩn `baseline.csv` và đăng ký vào MLflow Registry dưới nhãn `production`. Tiếp theo, mở một terminal mới và khởi chạy `uv run python serve.py` để bật FastAPI Server nạp mô hình v1 vào phục vụ dự đoán qua endpoint `/predict`. Khi hệ thống đang chạy, hãy kích hoạt bộ giám sát bằng lệnh `uv run python drift_detector.py` để quét tập dữ liệu thực tế `drifted.csv` (có thể kết hợp cờ `--check-mode combined` để phát hiện cả data và concept drift), từ đó làm cơ sở để chạy bộ điều phối bằng lệnh `uv run python retrain.py` (kèm cờ `--holdout` hoặc `--post-deploy-eval` cho các kịch bản stress test nâng cao); script này sẽ tự động gộp dữ liệu bằng chiến lược Sliding Window để huấn luyện v2, gắn nhãn `staging`, đưa ra yêu cầu phê duyệt `[y/N]` trên terminal, và ngay khi bạn gõ `y` đồng ý, hệ thống sẽ thăng cấp mô hình lên `production` đồng thời tự động gọi webhook `/reload` để FastAPI cập nhật phiên bản mới nhất mà không gây gián đoạn dịch vụ (zero-downtime).
